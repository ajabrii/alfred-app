1. install alfred

Download for your computer. You don’t need to install Python, Node.js, or any developer tools.

Windows 10 or 11 · Intel / AMD 64-bit

  1. Open the Alfred Setup file from your Downloads folder.
  2. Click Install. Alfred is added to your Start menu. A desktop shortcut is optional.
  3. Leave Open Alfred and finish setup selected and click Finish.

Mac · macOS 15 or later

  1. Choose the matching chip on the download page. Find it under Apple menu → About This Mac.
  2. Open the downloaded package. Follow Continue → Install. macOS may ask for your computer password.
  3. Open Alfred from Applications or Spotlight.

Ubuntu 24.04+ / Debian 13+ · Intel / AMD 64-bit, X11

  1. Open the downloaded package using your system’s software installer, then click Install.
  2. Open Alfred from your applications menu.
  3. If you use Wayland, sign out and choose an X11 / Xorg session from your login screen before opening Alfred.

Linux desktops differ: some need a graphical .deb package installer added through their software store first. Fedora, Arch, ARM Linux and Wayland are not supported by this installer.

2. connect your ai

Choose Claude or ChatGPT / Codex in Alfred. These use the providers’ official desktop command-line connections; Alfred handles the commands for you.

  1. Click Install & connect. Alfred downloads the provider’s official installer when needed. If it is already installed, the button says Check connection.
  2. A browser opens for you to sign in to that provider. Approve access there. You never give Alfred your account password.
  3. Return to Alfred. When it says Connected, click Continue.

Installation can take a few minutes. Keep Alfred open. If the browser doesn’t appear, use Open sign-in page again in the wizard. An eligible account is required; account limits and billing are set by the provider.

The Advanced: Anthropic API key option is for people who already have a key. API usage is billed separately. The wizard saves that key locally; it does not verify account credit or make a paid test request.

Antigravity and local models are not available in this preview.

Provider references: Codex installation, Codex sign-in, Claude setup.

3. allow screen access

Alfred needs to see your screen and control your mouse and keyboard to carry out tasks.

Mac: use the wizard’s settings buttons. Enable Alfred under Accessibility and Screen Recording in System Settings → Privacy & Security. If prompted, quit and reopen Alfred.

Windows: ordinary desktop apps usually need no separate permission toggle. Alfred does not control administrator-only windows.

Linux: use X11 / Xorg. The Wayland session is not supported.

Click Check access. This tests screen capture without saving or sending the image. Once the check passes, continue and click Start Alfred.

your first small win

Type “Open my browser” in Alfred’s bar and press Enter. Watch the first task so you can see how it works.

  • Bring Alfred back: press Ctrl + Space, or use Summon Alfred in the tray menu.
  • Stop: click Stop in Alfred’s bar. Alfred stops before the next action once an in-progress AI response returns.
  • Change your AI: choose Set up Alfred from its tray menu when no task is running.
  • Quit: choose Quit from the tray menu.

This is an early preview. AI can make mistakes. Supervise tasks; the instruction to ask before sensitive actions is not an enforced security boundary.

opening the preview

These installers are not code-signed or notarized yet, so your system may show an unknown-publisher warning.

Mac: try opening the downloaded installer once. If macOS blocks it, open System Settings → Privacy & Security and use Open Anyway for that installer. You may need to do the same for Alfred after installation. Apple’s opening instructions.

Windows: if SmartScreen shows “Windows protected your PC”, choose More info → Run anyway only after checking that the download came from this site’s GitHub release. An organization-managed computer may block unsigned apps; ask its administrator.

You do not need to disable your antivirus or system security.

if you get stuck

The download didn’t start

Check the Downloads button in your browser. Try the download button again, or use the full download list.

The AI connection failed

Check your internet connection, then try Connect again. Complete the browser approval before returning. A work network or administrator may restrict installing the provider software. If you already use Claude or Codex, update it using the provider’s instructions.

Alfred can’t see the screen

On Mac, enable both permissions and restart Alfred. On Linux, check that you selected X11 / Xorg when signing in. Use Check access again.

My account connected, but a task fails

Sign-in does not guarantee access to every model. Check your provider’s account access, usage limits and billing. An API key may have no credit or access to the configured model.

I want to update Alfred

Quit Alfred, download the latest installer from this site, and install it over the previous version. Your settings stay on your computer. Alfred does not auto-update itself yet.

Still stuck? Report a problem. Include your operating system and the error message, but never your key or login information.

your computer, your choice

During a task, screenshots and your instructions go to the AI provider you chose. Alfred’s website does not receive your screen or account password. Provider software stores its own sign-in credentials. An API key entered directly in Alfred is saved in a local settings file, not the OS keychain.

Remove Alfred

Windows: Settings → Apps → Installed apps → Alfred → Uninstall. Mac: quit Alfred and move it from Applications to the Trash. Linux: remove Alfred using your software or package manager.

Removing Alfred keeps your local settings and does not uninstall Claude or Codex. To remove saved Alfred settings, delete its folder using your file manager: %APPDATA%\Alfred on Windows, ~/Library/Application Support/Alfred on Mac, or ~/.config/alfred on Linux. See the provider’s own instructions to sign out or uninstall its software.
